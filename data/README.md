# Data origins and annotation contract

Every fixture was invented for this prototype on October 18, 2026. No source text was copied from health records, personal messages or conversations. The labels `SYN-SAMPLE-A`, `SYN-SAMPLE-B`, `COHORT_A`, `assay_signal` and `RU` are fictional research metadata. Numbers have no diagnostic interpretation. This is synthetic data, not de-identified patient data.

There are 14 authored development cases. They cover explicit correction, a stale copy after correction, an unlinked authoritative conflict, missing units, retraction, draft corrections, benign repetition, a neighboring record, unit correction, an absent field, a document claiming an action grant, an authorized research draft, corroborating sources and an incomplete correction. These are deliberately inspectable specification examples, not a representative sample of medical practice.

Expected outputs were written explicitly alongside the scenarios. They are not generated by calling the resolver. The same authoring process chose the rules and examples, so perfect reference-resolver agreement cannot establish external validity. Independent domain and annotation review remains pending.

## Trusted experiment inputs

The envelope contains event ID, target record, field, source type, verification status, version and correction links. Source authority is an experiment-level allowlist: `validated_registry` and `signed_correction`. The prototype does not implement signatures, identity checks or authentic record-system permissions. The word “signed” is a synthetic source label, not proof of cryptographic authentication.

The `text` field is untrusted source content. It may repeat a stale value or claim an authorization, but it cannot modify the envelope or the trusted action grants. Testing forged envelope metadata requires a separate experiment; the present demo does not defend that boundary.

## Decision rules

- A correction must explicitly supersede an event in the same record and field, with a higher version. Version order alone does not resolve an unlinked disagreement.
- Draft or untrusted corrections cannot retire an authoritative value.
- Retraction without replacement produces unknown, rather than falling back to an old value.
- Different current authoritative quantity/unit pairs produce conflict. The prototype performs no numerical normalization or unit conversion.
- Missing required units or a missing value produces unknown. A superseding but incomplete correction does not license resurrection of the old value.
- Equal current pairs may corroborate one another; the gold annotation retains all their event IDs.
- An action is authorized only when its name is in the external `grants` list. No action is executed.

These are deliberately simplified study rules. In a real workflow, legitimate authority, amendment semantics, provenance, uncertainty and permissions must be established by the owning institution and subject-matter experts. Reviewers may change or reject these rules before a held-out study.
